# Тренажер НМТ — Telegram Mini App

Гра всередині Telegram: українська мова, історія України та математика.
Це не бот із повідомленнями — це повноцінний застосунок, який відкривається в
Telegram кнопкою і має власний інтерфейс, анімації та налаштування теми.

## Що всередині

Усі файли лежать в одній папці — так їх приймає завантаження через сайт GitHub.

```
index.html          головна сторінка; тут же єдиний номер версії файлів
style.css           оформлення, усі кольори через CSS-змінні
app.js              уся логіка: екрани, тести, тема, збереження
config.js           адреса воркера для підрахунку користувачів
tex.js              показ математичних формул (власний, без сторонніх бібліотек)
nagolosy.js         233 слова
frazeologizmy.js    247 фразеологізмів
daty.js             244 дати, 12 тем
personalii.js       54 персоналії
pamyatky.js         95 пам'яток культури
formuly.js          150 формул, 10 тем
grafiky.js          малювання графіків і питання до них
praktyka.js         генератори задач із числами
f01.jpg … f54.jpg   портрети
p01.jpg … p95.jpg   фото пам'яток
cloudflare-worker.js бот, статистика і розсилка
bot.py              запасний варіант бота на Python
```

## Оновлення застосунку

Telegram і браузери надовго запамʼятовують файли. Щоб користувачі побачили
зміни, у `index.html` є один рядок:

```js
var ASSET_VERSION = 3;
```

Після кожної правки будь-якого файлу збільште це число на одиницю. Більше
нічого міняти не потрібно — усі файли підхоплюють його автоматично.

## Розділи

**Українська мова** — наголоси (постав наголос на потрібну голосну) і фразеологізми
(вираз і чотири значення).

У наголосах варіанти можна показувати двома способами, це вибирається в
«Налаштуваннях»:

* *Літери* — окремі голосні, як було спочатку.
* *Слова* — ціле слово з виділеною голосною, як у самому НМТ.
* *Як зручніше* (за замовчуванням) — літери, але в словах, де та сама голосна
  трапляється двічі («закінчити», «агрономія»), показується ціле слово. Інакше
  дві однакові кнопки «и» неможливо розрізнити, і правильну можна лише вгадати.
  Таких слів у списку 112 із 233.

**Історія України** — дати за 12 темами, персоналії (портрет і чотири імені; після
відповіді зʼявляється правильне імʼя, а вже потім — довідка про людину) і памʼятки
культури (фото і чотири назви).

**Математика** — три частини:

* *Формули* — 150 формул за 10 темами. Питання ставляться в обидва боки: і «яка
  формула це описує», і «що це за формула». Після відповіді показується
  розшифровка позначень. Є шпаргалка з пошуком.
* *Функції та графіки* — графіки малюються просто в застосунку, тому щоразу інші.
  Чотири режими: упізнай графік, упізнай формулу, перенесення графіка
  (y = f(x − a), y = f(x) + b, y = −f(x)) і властивості функції.
* *Практика* — задачі з числами, які складаються на ходу: прогресії, похідна,
  комбінаторика, область визначення, тригонометрія, відсотки, логарифми.

У кожному розділі є звичайний режим, раунд на 10 питань із результатом, робота над
помилками і список для перегляду з пошуком.

## Як підбираються неправильні варіанти

Головне правило: варіанти мають бути одного роду з правильною відповіддю.
Якщо на фото ікона, а серед варіантів «собор», «портрет» і «фортеця» — відповідь
видно, навіть не дивлячись на фото. Те саме з датами: коли правильна відповідь
«1648–1657 рр.», а решта — окремі роки, вибір очевидний.

Тому для кожного розділу визначено, що таке «один рід»:

| Розділ | Варіанти добираються так |
|---|---|
| Дати | такий самий вигляд дати: рік до року, період до періоду, століття до століття |
| Памʼятки | такий самий тип: ікона до ікони, храм до храму, живопис до живопису |
| Персоналії | та сама епоха |
| Фразеологізми | приблизно однакова довжина тлумачення |
| Формули | та сама ліва частина (S, V, P…) і та сама тема |
| Практика | типові помилки: збився на одиницю в показнику, забув поділити на два |

Якщо кандидатів одного роду забракло, вимога послаблюється поступово, а не
відразу до «будь-що».

## Як додати нові картинки

Покласти файл у `img/personalii/` або `img/pamyatky/` і дописати рядок у відповідний
файл у `data/`. Нічого в коді міняти не треба — рушій тестів спільний.

Перед додаванням варто стиснути зображення: портрети тримаються в межах 560 px
по довшій стороні, фото памʼяток — 760 px. Це приблизно 30–45 КБ на файл.

## Крок 1. Запустити локально у VS Code

Застосунок — звичайна веб-сторінка, тож жодного сервера для перегляду не треба.

Найпростіше: розширення **Live Server** у VS Code → правий клік на `index.html`
→ *Open with Live Server*.

Або через термінал у папці проєкту:

```bash
python -m http.server 8000
```

і відкрити <http://localhost:8000>.

Можна навіть просто двічі клацнути `index.html` — дані підключені через
`<script src>`, тому працюють і з `file://`.

Без Telegram усе теж працює: застосунок помічає, що Telegram немає, і бере
типову темну тему. Прогрес зберігається в браузері.

## Крок 2. Викласти на GitHub Pages

Telegram відкриває Mini App лише за адресою `https://`, тому сторінка має десь
жити. GitHub Pages для цього безкоштовний і без обмежень за часом.

1. Створи репозиторій, залий у нього все, крім папки `bot`.
2. Settings → Pages → Source: *Deploy from a branch*, гілка `main`, папка `/root`.
3. За хвилину зʼявиться адреса виду `https://USERNAME.github.io/nmt-trainer/`.

## Крок 3. Підключити до бота

**Варіант А — без жодного коду (рекомендую).**
У [@BotFather](https://t.me/BotFather): `/mybots` → твій бот → *Bot Settings* →
*Menu Button* → *Configure menu button* → вставити адресу з кроку 2.
Усе: у боті зʼявиться кнопка, яка відкриває тренажер. Нічого запускати не треба,
консоль падати не може — бо її немає.

**Варіант Б — із ботом.** Якщо хочеш ще й привітальне повідомлення:

```bash
cd bot
pip install -r requirements.txt
cp .env.example .env        # і вписати туди токен та адресу
python bot.py
```

## Налаштування теми

Екран «Налаштування теми» дає:

- **колір фону** — кружечок відкриває системну палітру з колесом відтінків
  (це `<input type="color">`, на телефоні виглядає як повноцінний вибір кольору);
- **колір акценту** — кнопки, прогрес, підсвічування;
- **заокруглення кутів** — повзунок.

Решта кольорів рахується автоматично: застосунок дивиться на яскравість
обраного фону і сам добирає читабельний текст, поверхні карток і лінії. Тобто
світлий фон дає світлу тему, темний — темну, і текст не зникає.

Якщо нічого не чіпати, застосунок бере кольори з теми самого Telegram.

## Статистика користувачів

Аналітика підключена, але вимкнена, поки не вписано ключ. Порожній `config.js`
означає, що застосунок нікуди не звертається взагалі.

Щоб увімкнути:

1. Зареєструватися на [TON Builders](https://builders.ton.org), створити проєкт.
2. У проєкті відкрити розділ **Analytics**, вказати адресу свого бота і домен,
   де лежить Mini App (той самий, що в Menu Button).
3. Отримати **API key** та ідентифікатор застосунку.
4. Вписати їх у `config.js`:

```js
window.ANALYTICS = {
  token: "сюди-api-key",
  appName: "ідентифікатор"
};
```

Після цього в кабінеті на TON Builders видно кількість користувачів, активних за
день / тиждень / місяць, нових і тих, хто повертається.

## Як зберігається прогрес

Статистика, серії правильних відповідей і список помилок лежать у
`localStorage` браузера. Якщо Telegram підтримує `CloudStorage` (версія 6.9+),
копія зберігається ще й там — тоді прогрес підхопиться на іншому пристрої при
першому відкритті.

## Що додати далі

- Історія: персоналії та пам'ятки культури з фото — формат «що це за собор?»
  працює в Mini App найкраще, бо картинки видно одразу.
- Іменний рейтинг або щоденна серія.
- Українська мова: іншомовні слова, лексичні помилки.

Щоб додати новий розділ, достатньо покласти файл у `data/` і описати, як із
нього робиться питання — рушій тестів уже спільний для всіх трьох модулів.
